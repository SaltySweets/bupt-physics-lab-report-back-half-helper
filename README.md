# bupt物理实验报告后半部分制作帮手

根据实验讲义、课件、原始数据和报告模板，辅助完成物理实验报告的后半部分：实验数据处理与讨论、思考题和实验总结。

**默认单次使用，无需安装。长期使用需自行配置。**

## 单次使用

1. 下载 [PROMPT.md](PROMPT.md)。
2. 将提示词文件与本次实验讲义或课件、原始数据记录、报告后半部分模板一起发送给能读取附件的助手；教师补充要求有的话一并提供。
3. 同时发送：

   > 请按这份提示词完成本次物理实验报告后半部分，仅本次使用，不进行长期配置。

如果所用工具不能读取 Markdown 附件，复制 [PROMPT.md](PROMPT.md) 中“可复制指令”之后的内容到对话，再附上实验资料。

## 报告规则

- 只完成报告后半部分，严格遵循所提供模板的大小标题、层级及顺序。
- 每组数据都要处理，并展示必要的文字说明、公式和数值代入过程。
- 表格只用于展示处理后的数值结果；完整源数据表仅作为数据来源，不放入报告。
- 逐组讨论结果、控制条件和误差影响，完整回答本次应做的思考题。
- 在第二部分设置“实验总结”小标题，适度概括主要结果和测量注意点。
- 每次从新文件判断实验项目、选做内容、处理公式和曲线安排。
- 遇到关键读数不清、必算数据缺失或要求冲突时集中核对，不编造读数或测量经历。
- 完成后复核计算、单位、有效数字与排版，默认输出可编辑 Word。

## Skill 文件

完整规则位于 [skills/physics-lab-report-back-half/SKILL.md](skills/physics-lab-report-back-half/SKILL.md)。可以把该文件作为本次任务的说明文件使用。

`agents/openai.yaml` 提供可选的 Codex 界面元数据，默认关闭自动匹配。文件不会自行安装到 Codex、DeepSeek Harness 或其他工具，也不会修改全局设置或长期记忆。

## 长期使用

长期使用由使用者按所用工具的说明自行配置。是否安装、安装位置以及是否开启自动匹配，由使用者决定；本仓库默认按单次任务使用。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `PROMPT.md` | 可直接发送或复制的通用提示词 |
| `skills/physics-lab-report-back-half/SKILL.md` | 完整技能规则 |
| `skills/physics-lab-report-back-half/agents/openai.yaml` | 可选的 Codex 界面与调用设置 |

本仓库仅包含可复用的规则和说明。实际实验的原始记录、扫描讲义及生成报告由使用者在各自任务中提供和保存。
